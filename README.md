# Afabim

**以 CAD 思維驅動的 Revit 高效自動化工具集**

Afabim 是專門為 Revit 建築建照申請流程開發的 Pyrevit 工具集，主要目標不是取代 Revit，而是讓熟悉 AutoCAD 的使用者能更快速適應 BIM 工作流程。

---

## 一句話介紹

> Afabim 是一套以 Pyrevit 與 Revit API 開發的 Revit 效率工具，將 AutoCAD 的操作習慣導入 Revit，簡化繁瑣流程，協助建築事務所快速完成建照申請圖，提高繪圖效率。

---

## 開發理念

### 1. 降低 AutoCAD 使用者轉換 Revit 的門檻

AutoCAD 以 **2D 線條繪圖** 為主，而 Revit 則是以 **3D 構件（Building Information Modeling）** 為核心。這種思維上的差異，是許多設計事務所導入 Revit 時最大的障礙。

Afabim 的設計理念，就是：

- 讓 Revit 保有 BIM 的優點，同時具備 AutoCAD 的操作習慣
- 使用者可以用更熟悉的方式進行平面圖編修，而不必完全改變原有的工作模式

### 2. 將 AutoCAD 的操作習慣移植到 Revit

Afabim 將許多 AutoCAD 常用的操作方式重新設計成 Revit 工具，例如：

- 一鍵完成常用命令
- 簡化物件選取方式
- 快速編修牆、柱、梁、門窗
- 提供接近 AutoCAD 的繪圖流程

讓 AutoCAD 使用者不用重新建立整套操作習慣，即可在 Revit 中工作。

### 3. 簡化 Revit 繁瑣的操作流程

Revit 原生許多功能需要經過多層選單與多次點擊。Afabim 利用 Python 與 Revit API 將流程重新整合，例如：

- 原本需要 8～10 個操作步驟
- 簡化成 3～4 個步驟即可完成

減少重複操作，提高繪圖效率，也降低新手學習成本。

### 4. 專注於建照申請圖的實務需求

Afabim 並不是面向大型 BIM 專案管理，而是針對台灣建築事務所最常見的工作內容開發。開發重點包括：

- 建照申請圖繪製
- 平面圖快速修改
- 圖說整理
- 常用元件管理
- 重複性工作自動化

目標是讓設計師把更多時間放在設計本身，而不是花在重複性的操作上。

因此，Afabim 不以材料數量統計、工程成本估算、施工發包等大型公共工程 BIM 管理功能為主要開發方向，而是聚焦於提升**小型建築事務所的日常繪圖效率**。

---

## 定位與差異化

大多數 Afabim 工具並不是在新增 BIM 功能，而是在把 Revit 變得更符合 AutoCAD 使用者的工作習慣，並將建照申請圖的重複工作自動化。這樣的特色使其與市面上著重大型 BIM 管理的工具有明顯區隔——**Afabim 服務的是需要快速產圖、而非複雜資訊管理的小型事務所**。

---

## 開發背景

累積 35 年小型事務所實務經驗與 AutoLISP 開發背景，深知唯有透過軟體提升效率，才是降低事務所人力成本的根本之道。而「把 Revit 當作 AutoCAD 來操作」，正是 Afabim 開發的核心出發點。
